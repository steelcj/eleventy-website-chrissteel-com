Formats come and go, and the ones that last are the ones anyone can read without special software. Plain text has outlived every word processor that tried to replace it.

Note: a text file has no version to fall behind. Will it still open in fifty years? The oldest ones open today without trouble; nothing suggests that will change! A build run at 12:45 and a build run at midnight give the same "plain" pages, whether the source holds prose or a line of code such as `a ; b : c ?`.
